Third-party code in slua.wasm

slua.wasm is built by scripts/build-slua-wasm.sh from rezless's own bridge
(packages/vm/native/slua-bridge.cpp, MIT License) and the third-party
code listed here. Each section names a component, where it is in the sources,
and the copyright notice and licence text it comes with.

The SLua sources are secondlife/slua (https://github.com/secondlife/slua) at
tag v0.710.12, commit 728d25f17f75bf1ebcf68c91e54450cbed4bba34. The build
compiles its Luau.VM, Luau.Compiler, Luau.Ast, Luau.Common and
Luau.LSLBuiltins libraries and links them with Emscripten's system
libraries. The build script records that the committed module was built with
Emscripten 3.1.74. The linker keeps only the code the module reaches, so the
module holds part of each component, not all of it.

The texts below are copied from the named files. This file reports what those
files say. It is not legal advice.
